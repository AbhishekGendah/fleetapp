# PDF fonts

Noto Sans 2.015 (Regular, Bold, Italic, Bold Italic), embedded in every PDF
the business app makes so any European name prints (review A3-4).

- From the npm package `@expo-google-fonts/noto-sans` 0.4.2 (12 Sep 2025),
  copied as files; the package itself is not a dependency.
- Licence: SIL Open Font License 1.1 (OFL.txt). Allowed for fonts by Abhi on
  5 Nov 2026 (docs/plans/review-fixes-batch-4.md). Embedding fonts in
  documents is allowed by the licence; the fonts are never sold on their own.
